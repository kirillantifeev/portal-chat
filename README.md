# Проект "Portal Chat"

Это realtime-чат с возможностью общения в режиме реального времени. В нём можно создавать каналы для группового общения, назначать администратора канала для редактирования списка участников чата, Также доступна регистрация и авторизация. Стек: React, HTML, CSS, JavaScript, Vite, Firebase, Zustand.

Структура проекта:

- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами


 Важные файлы:

- public — медифайлы для проекта
- src/lib/firebase.js — файл с конфигурацией firebase
- src/store — файлы для хранения состояний с помощью Zustand


 Компоненты проекта:

- src/components/login — компонент с регистрацией и авторизацией
- src/components/list — компоненты с реализацией создания каналов, подключения к существующим, отображения активных каналов пользователя
- src/components/chat — компоненты с реализацией чата
- src/components/details — компоненты с дополнительной информацией: поиск и удаление участников чата администратором, реализация выхода из системы
- src/components/notification — компонент с реализацией всплывающих подсказок 

## Установка
Для установки и запуска проекта необходимо выполнить команды

```
npm i
или
```

```
yarn i
```

## Сборка

```
npm run build
или
```

```
yarn build
```

## Запуск проекта на локальном сервере 

```
npm run dev
или
```

```
yarn run dev
```
